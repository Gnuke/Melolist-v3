# Melolist-v3 PRD Generation Request

[아카이브 2026-07-22] PRD 최초 생성 요청서 스냅숏 — 갱신하지 않음. 현행 문서는 docs/README.md 색인 참조.

## Project Overview

Melolist-v3는 기존 Melolist-v2(Vue + Node.js)를
최신 기술 스택으로 마이그레이션하는 프로젝트이다.

기존 기능은 최대한 유지하면서
아키텍처 개선,
사용자 경험 개선,
AI 기능 확장을 목표로 한다.

이번 단계에서는
기존 프로젝트 분석 후
Melolist-v3를 위한 PRD.md를 작성한다.

단순한 기능 나열이 아니라
실제 개발 문서 수준의 PRD를 생성한다.

---

# Project Goals

- Nuxt.js 프로젝트를 React + Spring Boot 구조로 마이그레이션, 형상관리의 용이성을 위해 Frontend와 Backend로 프로젝트 폴더를 분리하는 것을 희망함
- 유지보수가 쉬운 구조
- 확장 가능한 Domain 기반 아키텍처
- 모바일에서도 사용하기 쉬운 UX
- 향후 AI 기능 확장이 쉬운 구조
- 기존보다 높은 완성도의 UI/UX

# UI/UX Direction

기존보다 훨씬 현대적인 디자인을 목표로 한다.

방향 (상용 서비스 수준 · 실제 출시 가능한 완성도)

- Spotify · Notion · Apple · Linear 수준의 완성도
- 개발자 프로토타입 느낌이 아닌 실제 서비스 느낌
- Modern Premium UI · Dark Theme 기본
- Glass Morphism은 최소한만 사용
- Flat하지 않고 레이어와 깊이감(그림자·글로우·inset)
- 여백 적극 활용 · 고급스러운 타이포그래피
- Card UI · 모바일 우선 · 반응형

## Design System (필수)

컴포넌트 라이브러리 (직접 만들지 말고 조합한다)

- shadcn/ui
- Radix UI
- Framer Motion (motion)
- Lucide Icons

Motion Design 적극 사용

- Framer Motion: spring / scale / opacity / blur transition / stagger animation
- 페이지 진입 fade
- 마우스 hover 효과
- 버튼 클릭 애니메이션
- micro-interaction

타이포그래피

- Inter (Variable), 자체 호스팅

색상

- Black         #090909
- Surface       #161616
- Accent        #5B8CFF
- Accent Hover  #7EA6FF
- 빨간색(#EF4444)은 오류 또는 녹음 중에만 사용한다

특수 인터랙션

- 마이크 버튼은 Apple Siri 수준의 인터랙션으로 구현한다

UX 개선도 함께 제안한다.

예시

- Swipe Gesture

# Important

PRD는 단순한 기능 목록이 아니라

실제 개발자가 사용할 수 있는 수준으로 작성한다.

기존 프로젝트를 충분히 분석한 뒤
Melolist-v3에 맞게 개선사항을 적극적으로 제안한다.

기존 코드를 그대로 옮기는 것이 아니라
더 나은 구조를 설계하는 것을 우선한다.

UX와 유지보수성을 가장 중요하게 고려한다.
